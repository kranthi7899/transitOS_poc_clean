# Claude Haiku integration decisions (2026-10-12)

| ID | Decision | Where | Status | One-line reasoning |
|---|---|---|---|---|
| A189 | Claude Haiku (`claude-haiku-5-5`) is the only model allowed; it sits behind the existing `Reasoner` interface in one module (`workflow/reasoning_anthropic.py`); the SDK is an optional extra (`llm`) imported lazily; the default stays the stub. | `workflow/reasoning_anthropic.py`, `reasoning.py::reasoner_from_env` | decided (owner: Haiku only) | Owner asked for Haiku and minimal cost; CLAUDE.md rule 7 says one access point. |
| A190 | The model's job is to choose among options clearance already allows, decide pull-now vs pull-at-block-end, and explain; it decides no rule and its answer is re-validated by `validate_output` (the one rule implementation). | `reasoning_anthropic.py` prompt, graph `reason` node | decided | Hard limits are code (rule 3); a cheap model must not be able to widen what is allowed. |
| A191 | Cost controls: default cap $3, hard maximum $10, checked BEFORE each call against that call's worst case; persistent totals file; 60 calls per process; effort low, max_tokens 700, one retry (the graph's), one SDK retry, 30 s timeout. | `LLMBudget`, `AnthropicReasoner` | decided (owner: stay within $5-10) | Cheapest settings that still work; the cap is a refusal, not a warning. |
| A192 | Prices ($0.10 in / $0.50 out per million tokens, prompts up to 100K tokens) are written in code from the API reference of 2026-10-06; re-check them before relying on the totals. | `PRICE_IN_PER_MTOK`, `PRICE_OUT_PER_MTOK` | open | Prices change; the cap uses worst-case estimates so a small drift cannot overspend. |
| A193 | The key comes only from `ANTHROPIC_API_KEY` or the git-ignored `.env.local` (only that variable is read, never overriding the environment); it is never logged, stored or put in a prompt; a test fails the build if a key-shaped string is tracked. | `load_local_env`, `tests/test_repo_hygiene.py` | decided | A leaked key is the worst outcome here and cannot be undone. |
| A194 | Prompt-injection stance: a whitelist of fields reaches the model, free text is cut to 120 characters, `<` is escaped, the system prompt calls the data inert, and the answer is validated whatever it says. | `build_prompt`, `SYSTEM` | decided | Vendor text (names, defect descriptions) is untrusted data. |
| A195 | Choosing `anthropic` without a key (or with the SDK missing) is a clear start-up configuration error, not a silent downgrade to the stub. | `reasoner_from_env` | decided (supervisor, owner may overrule) | A misconfiguration the owner should see; the stub is one unset variable away. |
