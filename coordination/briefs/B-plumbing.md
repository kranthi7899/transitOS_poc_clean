# Track B — Event plumbing (src/transitos/plumbing/, tests/plumbing/)
Build: (1) `bus_sqlite.py` implementing contracts/bus.py Producer+Consumer on SQLite (topics, partition-by-key ordering, per-group committed offsets, replay from offset 0, at-least-once; commit after side effects). Keep a `KafkaBus` stub class with the same interface and a clear NotImplemented. (2) `outbox.py` table + `relay.py` (fetch unsent -> send -> flush -> mark sent; crash between flush and mark republishes). (3) `watch/` adapters: maintenance poller (PM transition -> PMOverdue, WO opened/closed -> WorkOrderOpened/Closed), scheduling poller (VehicleStatusChanged), workforce poller (OperatorAvailabilityChanged), telematics webhook receiver (verify HMAC, map fault -> VehicleFaultDetected, DVIR -> DefectReported) + backfill poller reconciled by event ID. Each poll: cursor + last-seen + outbox rows in ONE DB transaction; outbox UNIQUE(event_id) drops repeats; ids from contracts/ids.py. Adapters talk to mocks through an injected httpx client (TestClient in tests). (4) `crosswalk.py` implementing contracts/crosswalk.py (SQLite; unresolved queue; resolve() returns parked events), and `crosswalk_service.py` (consume events.raw group `crosswalk` -> enrich with VehicleRefs -> publish events.resolved keyed by canonical vehicle ID; unknown ID -> unresolved + events.failed; idempotent via processed table). (5) `audit.py`: consumers `audit-raw`/`audit-resolved` writing append-only audit tables + a DecisionRecord store API used by workflow/panel (`record_decision(DecisionRecord)`, `list_for_run`). 
Tests (must exist): crash mid-poll loses/duplicates nothing; relay crash after send republishes and consumers dedupe; replay of events.raw yields no extra resolved events; per-vehicle ordering on resolved topic across two products; unknown vehicle queued then fixed -> republished; HMAC reject; duplicate webhook ignored. For mocks use TestClient against Track A's apps if available on main; otherwise write minimal local fakes in tests/plumbing/fakes.py following docs/MOCK_API.md exactly.
