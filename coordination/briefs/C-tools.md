# Track C — Tools, adapters, registry, policy (src/transitos/tools/, tests/tools/)
Build: (1) `read_adapters.py` / `write_adapters.py` implementing contracts/tools.py ReadTools/WriteTools over the mock HTTP API (injected httpx client; timeout 3s; retry w/ backoff on 429/5xx; unavailable -> `Result.unavailable(product)`; never guess). Map native objects to canonical objects. Maintenance writes: `find_open_work_order` first (reuse human-opened WO, note=already_open); send Idempotency-Key; read back after write. Scheduling/workforce have no idempotency keys: keep an `idem_store.py` (SQLite) so a repeated key returns the prior result without calling the product. Each write adapter re-checks hard limits before calling the product (policy). (2) `registry.py`: per-agency YAML config (design: registry maps tool -> adapter id; `agency-042` -> *_mock_v1; an `agency-077` entry -> v2 variants if Track A provides them) returning a ToolSet object exposing all ReadTools+WriteTools; swapping a product = changing a config line. (3) `policy.py`: load per-agency policy YAML into contracts/policy.AgencyPolicy; `kill_switch(agency)` read live (file/SQLite flag toggled by panel); `check_hard_limits(...)` pure functions: never pull last spare (min_spares), operator hours (hours_today + block hours <= max), lift qualification, spare meets needs. (4) `contract_tests.py` reusable suite parametrised over adapter implementations. 
Tests: unavailable on dead mock; idempotent create_work_order (retry -> one WO); human-opened WO reused; compensation pairs work (cancel only system-created); kill switch blocks writes; hard limits reject even if caller passes bad params. Use Track A's apps via TestClient if on main, else fakes per docs/MOCK_API.md.
