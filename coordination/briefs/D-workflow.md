# Track D — Workflow brain (src/transitos/workflow/, tests/workflow/)
Build the LangGraph workflow with SqliteSaver checkpointer (langgraph-checkpoint-sqlite), thread_id = run_id. Nodes: gather (parallel reads, no writes) -> check (hard limits in code via an injected `limits` object) -> reason (via `reasoning.py` client interface: `StubReasoner` default that returns a valid plan from feasible lists, plus `code_ranked_fallback`; validation: schema, chosen spare/operator in feasible lists, pull_at in window; one retry then fallback flagged `fallback_used`) -> policy (autonomy per step, kill switch) -> propose (persist plan + decision record) -> await_approval (INTERRUPT ONLY, no writes) -> route (approve/edit -> revalidate; reject -> close_rejected; expired -> escalate) -> revalidate (re-gather+check; stale -> back to reason with plan_version+1) -> execute_step (ONE write per pass in saga order from contracts/tools.SAGA_ORDER; kill switch checked before each write; record step to state before next pass) -> on failure compensate in reverse then escalate (compensation failure -> escalate with exact state) -> wait_for_repair (INTERRUPT ONLY, resumed by WorkOrderClosed) -> return_to_service -> close. Also `starter.py`: consume-style function `handle_event(event, runs_index, ...)`: dedupe by event id, one active run per vehicle (second start event attaches as context), resume on RESUME_TYPES, signal on UPDATE_TYPES (invalidates plan). Also `timers.py`: approval timeout via sim clock -> expired -> escalate.
Depend ONLY on contracts + injected interfaces. Write `fakes.py`: in-memory ReadTools/WriteTools with fault injection (reject write at step N, fail compensation, spare vanishes, kill switch flip).
