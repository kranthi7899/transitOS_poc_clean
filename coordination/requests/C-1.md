# C-1: clearance items, plan and decision-record fields, vehicle_fit, length attributes (additive, v1.2)

Phase 10 Amendment A. The plan and decision record must show every derived, assumed, unverifiable or not-evaluated
rule, and an approver acknowledgement.

New `contracts/clearance.py`:
- `ClearanceItem(rule: str, status: Literal["pass","warn","unverifiable","not_evaluated","violation"],
  basis: Literal["native","derived","assumed","unknown"], detail: str = "", requires_ack: bool = False)`

Existing models, all new fields optional:
- `Plan`: `clearance: list[ClearanceItem] = []`, `rank_reason: str = ""`, `vehicle_fit: str | None = None`
- `RunState`: `acknowledged: list[str] = []`
- `DecisionRecord`: `clearance: list[dict] = []`, `acknowledged: list[str] = []`, `vehicle_fit: str | None = None`
- `AgencyPolicy`: `vehicle_fit: Literal["exact","allow_larger"] = "allow_larger"`
- `Needs`: `max_vehicle_length_ft: float | None = None`
- `Vehicle`: `length_ft: float | None = None`

Affects: C (clearance module, adapters), D (plan, graph), E (panel display and acknowledgement), F (scenarios).
