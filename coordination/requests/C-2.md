# C-2: per-row unknown fields (additive, v1.2)

Reviewer R1 finding F3 (Step 1 review): the canonical objects cannot say "this value was missing or blank in the
source". `Operator.hours_today` defaults to 0.0 and `lift_trained` to False, so a blank cell becomes a silent pass or
a violation. Amendment A: missing data is never a violation and never a silent pass.

Add (all optional, default empty; names are the contract field names that were blank or absent for THIS record):
- `Operator.unknown_fields: list[str] = []`
- `Vehicle.unknown_fields: list[str] = []`
- `Needs.unknown_fields: list[str] = []` (keys the block did not declare, so "no requirement" is not assumed)

Read adapters fill them per row; clearance treats a listed field as basis `unknown` for that record only, ahead of
the product-level capability profile. Affects: C (adapters, clearance), A (mock switch to blank cells), F (golden).
